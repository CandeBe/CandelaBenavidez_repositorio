Hola! En esta segunda instancia de proyecto individual desarrollé mi portfolio utilizando HTML5 y CSS, aplicando etiquetas semánticas y propiedades de estilo vistas en clase e investigando en internet!

Trabajé con una resolución de pantalla de 2560 x 1600 px.

El proyecto está compuesto por cuatro archivos HTML:

index.html (sección “Sobre mí”)
galeria.html (sección donde muestro mis trabajos)
experiencia_estudios.html (sección “Experiencia, educación y habilidades”)
contacto.html (donde podes contactarme)
Todas las páginas se encuentran vinculadas entre sí mediante una barra de navegación fija que permite moverse entre secciones de forma simple y accesible.
Funcionalidad de la página:

NAV GENERAL:

Botón “Sobre mí”
Botón “Galería”
Botón “Experiencia y estudios”
Botón “Contacto”
El contenido se divide en:

Presentación personal con imagen y descripción
Galería de trabajos
Experiencia laboral, Educación, Habilidades
Contacto
Estilos (CSS):
Los estilos se trabajaron en una hoja externa (estilos.css), donde se aplicaron:

En estilos con :root:

Tipografías personalizadas mediante @font-face

Paleta de colores definida

Márgenes y espaciados

Fondos con imágenes

Uso de flexbox para la disposición de elementos en distintas secciones

Hovers y truquitos para la galería dentro de la misma hoja.

Elegi el index.html para aplicar el diseño responsive. Se implementaron Media Queries para cambiar el formato cuando el ancho de pantalla sea menor a 600px.
Menú Hamburguesa: Integración de un menú desplegable para navegación móvil.
Imágenes fluidas: Todas las imágenes se adaptan al ancho del contenedor, manteniendo sus proporciones originales.
